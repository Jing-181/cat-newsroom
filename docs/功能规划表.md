# 功能规划表

> 面向长期产品演进的目标清单。优先级表示方向，不代表已经排入近期开发；具体执行项以《任务表》为准。

| 阶段 / 目标 | 目标说明 | 预期能力 | 衡量方式 | 优先级 |
| --- | --- | --- | --- | --- |
| P1：可靠的个人数据底座 | 让用户在任意设备上稳定、安全地访问自己的数据。 | 完整备份与恢复、导入导出、冲突可解释、同步历史与失败可见性、账号与存储管理。 | 同步失败可恢复；关键数据可由用户自主导出和恢复。 | P0 |
| P2：统一且可访问的体验 | 在保留报刊视觉语言的同时，提高桌面、移动、键盘和辅助技术使用体验。 | 更一致的响应式布局、深浅色/高对比主题、无障碍语义与焦点管理、性能优化、离线可用。 | 核心流程在常见屏幕和键盘操作下顺畅；页面加载和交互性能可量化。 | P0 |
| P3：计划—执行—复盘闭环 | 从分散记录升级为可持续执行的个人节奏系统。 | 周/月目标、日程与提醒、任务/习惯/专注关联、模板、周期性任务、复盘仪表盘。 | 用户可设定目标、完成日常执行并获得可行动的复盘反馈。 | P0 |
| P4：训练能力进阶 | 将训练日志发展为可长期使用的训练管理工具。 | 自定义动作与训练模板、训练计划排期、容量/强度趋势、PR 记录、恢复与疲劳标记、单位偏好。 | 可从计划进入训练并持续追踪进步，历史数据可视化清晰。 | P1 |
| P5：个人知识与内容管理 | 让日记、收藏和阅读记录沉淀为可检索、可再利用的资料。 | 标签体系、全文检索、筛选归档、阅读清单、网页剪藏、关联记录与附件管理。 | 用户能快速找回内容，并在复盘和写作中复用。 | P1 |
| P6：智能但可控的助手 | 以用户授权和可解释为前提，提供高价值自动化建议。 | 可配置 AI 周报、目标/训练建议草稿、记录归纳、异常提醒、提示词与数据范围控制。 | 建议可编辑、可追溯、可关闭，且不替用户执行关键操作。 | P1 |
| P7：开放与协作生态 | 在个人数据主权前提下支持连接外部工具和有限分享。 | 日历、健康平台、快捷指令/API、可分享的只读周报或模板、权限控制。 | 外部集成不破坏数据隔离；分享范围明确且可随时撤销。 | P2 |

## 规划原则

1. **数据主权优先**：导出、删除、权限与 AI 数据范围必须由用户控制。
2. **本地优先、云端增强**：离线记录不应被网络状态阻断；联网后可靠同步。
3. **渐进扩展**：先完善现有静态页面和共享领域逻辑，再评估框架重构，不为技术升级牺牲稳定性。
4. **建议不替代判断**：运动、健康和财务相关能力只提供记录与一般性提示，不提供诊断或投资决策。
