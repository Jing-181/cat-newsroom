# 生活工作台首批优化 · 2026-11-12

版本：2.22.0。范围为首页减负、随手记、生活时间线，沿用报刊主题和既有数据模型。

## 页面行为

- 首页：紧凑日期问候、随手记、最多五条未完成事项（置顶优先）、本周训练次数与草稿入口、今日状态、番茄钟、每日一卡、训练周复盘。训练明细收进展开区；完整本周状态曲线放在洞察页。
- 旧首页排序仍生效，重复的焦点/概览卡仅停止展示，原配置不删除；设置页继续使用既有卡片标识。
- 随手记：记一笔存入日记，加事项存入待办，支持 Ctrl/Cmd + Enter。中文组合输入期间不提交。本机保存失败保留输入；本机成功但同步调用异常时明确提示，避免重复提交。
- 草稿：使用 sessionStorage，按当前账号隔离；在当前标签页切换路由或刷新数据后仍保留。草稿不跨设备同步，关闭标签页后不保证保留。已保存记录继续使用原有同步层。
- 时间线：`#/timeline`，从侧栏或首页进入；只读聚合日记、收藏、已完成训练。默认隐藏样板记录，可按类型筛选；每批 30 条。日期必须是有效 YYYY-MM-DD，缺失/无效日期统一列在末尾，不用更新时间推测生活发生时间。同日记录不推断具体时刻。
- 时间线文字由 Vue 转义；图片记录通过原模块查看，按钮跳转模块而非具体记录详情。运动图鉴入口移到运动页，原图鉴 URL 保持有效。

## 数据边界

不新增同步模块、不改存储主键、同步协议或 workout_session。状态评分仍是原有本周七天数据，不提供跨周心情档案。训练周复盘继续只读已有云端视图。未增加 AI 聊天、复杂 Todo 或奖励机制。
