2026-11-07 暂停。不是技术跑不完，是造型这一层该由人定，我替着做了太多轮。

## 现在的状态

- 代码还在原位，`npm test` 全绿，`npm run build` 通过。
- 15 条动作、两套骨架解算（侧视 / 正视）、四套皮肤（线条 / 轮廓 / 体积线 / 3D）都在。
- 但**画法规范全部作废**，见 `docs/motion-keep.md` 第三节。
- 不要再往这条路上加东西。它可以作为解算器和轨迹数据的参考实现在。

## 走过什么、停在哪

| 轮次 | 做了什么 | 结果 |
|---|---|---|
| 骨架 | 按 D&C 1966 重定分段比例 | 成立，腕落髖下 4.5，站立膝屈 2.3° |
| 约束 | 握点锚定、杠走直线、膝钉凳面 | 成立，动作轨迹不再靠手调 |
| 映射 | 修好 5 条动作静默回落 idle | 成立，有测试守着 |
| 器械 | 杠铃/单杠/哑铃/绳索/训练椅 | 成立，器械与骨架分离 |
| 视角 | 加正视骨架，侧平举改正面 | 成立，但属于画法规范，已作废 |
| 造型 | 五轮，头身比、线宽、关节、剪影 | **没成**。缺基准图，一直在猜 |

造型那一轮是这次停下来的原因。最后一轮拿到参考图，按它把比例改对了（头占身高 1/4、四肢细、不打关节点），但那是照图抄，不是设计。

## 留下的东西

- `src/lib/motion/core.js`：骨架解算、关节角度、约束求解
- `src/lib/motion/clips.js`：15 条动作的关键帧数据
- `scripts/motion-invariants.mjs`：动作不变量检查（握点钉死、杠走直线、膝不动等）
- `docs/motion-keep.md`：人体结构 + 运动轨迹，**唯一需要继承的文档**
- `docs/skeleton-design.md`：骨架设计，画法部分已过时
