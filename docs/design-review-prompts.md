# 设计审查提示词 · 手册

给 Jing 用。八条提示词，每条配一个真实示例，示例全部取自这个仓库的「运动健身」训练页。

## 怎么用

一次只跑一条。八条一起跑，模型会生成一段听起来很专业、但每个位置都指不准的评语。

输入永远是三样：**截图** + **这张图要解决的问题** + **不能动的东西**（数据模型、已有 token、已通过的交互）。少一样，评语就会朝「重做一版」滑。

输出格式写死在提示词里：现象 → 为什么错 → 方向。禁止形容词单独成句。

---

## 一 · 第一眼测试

> 用途：判断层级是否成立。眼睛不知道先看哪里，后面全白搭。

```
你是界面评审。只看这一张截图，不要推测实现。
先眯眼（把图缩到 20% 大小）看三秒，然后回答：
1. 最先跳出来的是哪一块？用一句话描述它的位置和内容。
2. 那块东西是不是这张页面此刻最该被先看到的？如果不是，说清它抢走了谁的注意力。
3. 缩到 20% 之后还能分辨出几个块？少于三个，说明页面没有分组。
只回答这三点，不要写建议，不要用「不够聚焦」这类判断词。
```

**示例**（训练页第一版）

> 最先跳出来的是标题下方那个 `0 kg`，位置在页面左侧三分之一高度。它不是此刻最该被看到的：这是一张刚开的草稿，最该被看到的是第一个动作和它的组。这个 0 抢走了两样东西：页面最大的一档字号，和唯一被两条线夹住的位置。缩到 20% 后只能分辨出三个块：顶部深色栏、数字带、下面一整片同灰度的文字。

---

## 二 · 层级清点

> 用途：找出「用了太多手段表达同一件事」。层级混乱几乎都能被数出来。

```
把这张图里建立层级的全部手段各数一遍，逐项报数：
字号（列出所有不同字号与出现次数）、字重、文字颜色（列出色值或明暗档）、分隔线（几档轻重、分别出现在什么层级）、留白档（相邻间距有几种不同值）、背景色块、圆角与描边。
然后回答：同一层级的事实用了几种手段？有没有一个层级同时被三种以上手段强调？
禁止给建议，只报数和指出重复。
```

**示例**

> 字号 5 档（17 / 13 / 12 / 11 / 10），字重 3 档，文字颜色 3 档，分隔线 4 种轻重共 8 条，留白 6 种。问题：动作之间、统计带下沿、标题下沿这三个不同层级都用了一样的深线，线因此不再表示层级；留白 6 种，但动作块内部四行用的是同一种，所以「动作」这个单位在视觉上不存在。

---

## 三 · 线的语义审计

> 用途：分隔线是最容易被滥用、也最容易被忽略的层级手段。

```
列出这张图里每一条线，做三列：位置 / 它分隔的是同级还是不同级 / 如果删掉它，分组还成不成立。
判据：同一条线重只能对应一个层级；不同层级必须用不同轻重。
最后给一句：这张图里有几条线是多余的。
```

**示例**

> 统计带下沿（深）分隔不同级，但和动作之间的线同重，删掉后分组不成立但会少一档歧义；动作之间（深）必须保留；组与组之间（浅）同级，可以删掉一半靠间距分组；动作卡脚部上沿（浅）多余，它下面就是下一张卡，两线相距不到 20px。结论：8 条里 3 条多余。

## 四 · 间距节奏

> 用途：等距 = 没有分组。这条几乎能解释一半「太平了」的页面。

```
量出所有纵向间距（单位 px 或截图比例），按出现顺序列出来。
判据：相邻两组的间距比值小于 1.5，读者不会认为它们是两组；块内元素之间与块与块之间必须拉出至少 1.5 倍差。
指出哪些位置本该分组却用了等距，并给出哪一处该放大、哪一处该收紧。
```

**示例**

> 顺序：8 / 8 / 8 / 8 / 12 / 12。动作名→上次 8，上次→第 1 组 8，第 1 组→第 2 组 8，第 2 组→加一组 8。四段等距，所以「这个动作完了」在视觉上没发生。该放大的是动作之间的 18→28；该收紧的是名字与「上次」这条事实，8→2。

## 五 · 边缘状态

> 用途：样板好看、空状态灾难，是最常见的一类。评审时先看空。

```
假设这是同一个界面的四个状态：完全为空、只有一条数据、每条数据都极长、数据是一个 0。
逐个指出：
- 哪个元素在某个状态下会变成没有意义的占位；
- 哪个元素在这个状态下仍然说话，且说的是真话；
- 有没有把「没有」渲染成了「0」或「无」以外的形式。
只报事实，不要给修法。
```

**示例**

> 空状态下，页面最大的字是 `0 kg`，它把一个「没有数据」说成了「一个等于零的度量」；右上角 `0 组 0 次` 同理。组行写成 `0 kg × 0`，长相和一条真实记录一样，读的人无法判断这是没练还是练了没记。唯一在这个状态下说真话的是标题里的日期。

## 六 · 字体尺度与可读性

> 用途：手机上 10–12px 的正文永远读着累，而它常常被当成「克制」。

```
列出所有字号、行高、字间距，标出对应内容类型（标题/正文/标签/数字/注释）。
判据：正文不小于 14px（中文），注释不小于 11px 且只用于非关键信息；数字必须等宽（tabular）；同一行内两个元素字号差小于 2px 时，它们实际上是同一层级，检查是不是漏了主次。
指出哪一档字号在承担两种不同角色，或哪两个字号差了一档却表达同一件事。
```

**示例**

> 出现 17/13/12/11/10 五档。`11` 同时用于「部位器械」「组间歇建议」「动作说明」三种不同角色，其中组间歇是可选信息、动作说明是入口，两者被压成同档；`10` 只出现在一处，单独一档不构成尺度。数字未全部使用 tabular，「4,720」和「56」上下不齐。

---

## 七 · 一致性 / token 漂移

> 用途：单页好看、全站不统一，是手写样式积累到后期的典型病。

```
对照给定的设计 token（颜色、圆角、阴影、间距、动效时长）审计这张图：
逐项列出界面上实际出现的值与 token 的对应关系，标出没有对应 token 的字面量，以及同一个 token 在不同层级被重复使用的情况。
结论只用一句：这张图里有几处字面量、几处 token 复用错了层级。
```

**示例**

> 圆角：卡片 12、输入 10、弹窗 20 都有对应 token；但「动作进展」折叠块用了卡片圆角 + 描边 + 背景，落在一个明确不做卡片的页面里，属于 token 用对了、语义用错了。颜色：深色线用了 `--text`，它本来是文字色，被借来当分隔线，导致这条线和正文抢同一个视觉重量。

## 八 · 记忆点与自证

> 用途：做完之后回头验一遍，这页除了「没出错」还有什么。

```
合上截图，凭记忆回答三个问题，然后展开对照：
1. 这一页有哪一处是我能画出来的？（一条线、一个数字、一个动作）
2. 用一个词形容这一页的语气，再对照实现，看是元素给的还是内容给的。
3. 如果遮住 logo 和标题，还能认出是哪个产品吗？靠什么认出来的？
如果一个都答不上，直接说「这页没有记忆点」，不要替它找补。
```

**示例**

> 记得住的只有那个 0，因为它太大了，而它是错的。语气上想做成「刊物内页」，但刊物的语气是标题给的，这一页最重的东西是统计数字，所以语气实际来自仪表盘。遮住标题认不出是哪个产品，唯一可辨的是配色。

---

## 三条失效模式

1. **让它给方案**。方案会盖掉判断，最后你得到一版更整齐但同样错的东西。要它先只报事实。
2. **一次问八条**。它会把每条都答成半句，你会以为自己收到了完整审计。
3. **接受没有坐标的评语**。「层级不清」不是结论，「动作名 17px、部位 12px、组进度 12px，三者挤在同一行基线」才是。

---

## 最后一句

审美不是风格偏好，是**判断每一样东西是否在承担它宣称的角色**。上面八条其实只在问三件事：层级有没有分出来、分组有没有发生、边缘状态有没有说真话。
