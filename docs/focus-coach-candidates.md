## 最新纠正：扁平火柴人基线（优先于下方历史设计）

用户明确：火柴人做运动，头只要空心圆，不要脸、眼睛、嘴。身体与四肢是细线；禁止胶囊肢体、双描边体块、立体脚块。Q 来自每动作固定的上/下肢相对比例与姿态，不是肌肉或粗描边。流畅来自连续轨迹、重心/关节协调和节奏，不使用弹性缩放、滑动支撑或负重动作过冲。此项作为后续所有动作基线，引体保持原样；不恢复旧复杂美学硬规范。

## 设计决定

用户方向：练上肢放大上肢比例，练下肢放大下肢比例。用固定长度、体块和手脚尺寸表达，不要求夸大肌肉，不仅增加描边粗细。

最新授权接入：深蹲和卧推已通过 demos.js 注册表替换训练页及图鉴的旧版，匹配新皮肤；视觉仍待验收。旧版仅保留于预览对照。引体的 demo-clips.js / demo-skin.js 原样保留，不修改比例、时序、画法。两条新候选共用圆润轮廓、纸色体块与安静的点眼表情；引体保留旧画法作对照，不强行统一。

- 深蹲：大腿/小腿 31/29，上臂/前臂 15/15，躯干 26；强调腿脚，收短上身。双脚在身体左右真实分开，脚底多边形固定于 z=0；杠轴通过身体局部的上背表面锚点，左右手附着同一轴。
- 卧推：大腿/小腿 20/20，上臂/前臂 25/23，躯干 32；强调肩、臂、手，腿脚收小。凳面、头背骨盆接触点和脚底固定。双肩分别求解到两个握点，肘 hint 相对身体朝外/脚端，下放时加入向下分量。
- 以上均为绘图单位与候选比例，不是解剖标准或训练处方。

少量 3D 点 → 固定正交 3/4 相机 → SVG。无 WebGL、外部依赖、渲染后非均匀拉伸。骨长与比例在 IK 前指定；不可达/退化 hint 直接报错，不静默伸长。单根完整杠轴、双握点、两端圆盘来自同一个器械坐标系。

SVG 使用预分配节点与按深度排序的简单绘制，圆润肢体/躯干体块由固定世界关节投影形成。深度排序是分段级近似，不是完整三维遮挡/碰撞系统；交叉遮挡和头脸朝向仍需视觉检查。没有宣称 IK 长度或 hint 测试构成专业动作认证。

## 预览 brief

入口 `/preview/motion.html`，直接 96px：`/preview/motion.html?size=96`，深色加 `&dark=1`。
