# 2.18 轻量记录

## 入口

- 事项：按版本或主题分组，旧事项自动归入零散事项。
- 随记：文字或照片任意一种即可保存；保留旧日记标题、心情和日期。
- 习惯、阅读：放入「更多模块」，首页不再展示相关卡片。
- 记账：退出主导航及首页；原数据和备份能力保留。

## 操作

事项在分组内输入、回车连续添加，中文输入法确认不提交；点击事项编辑，在「版本 / 分组」中移动。完成项收起并可撤销，单条删除可撤销；整组删除需要确认。新建的空分组在添加第一条事项后随记录保存，空分组和临时折叠状态不跨设备同步。

随记新增内容和照片置于首层，支持粘贴图片。不生成装饰配图。新建草稿按当前账号 ID 保存在本机，保存成功后清除；没有可确认账号时不写共享草稿并提示用户。上传失败可在当前编辑器内重试，关闭后未上传的本地照片需要重新选择。已上传图片地址随草稿恢复。

## 数据边界

保持 `cat-newsroom-data-v2`、现有同步协议与 workout_session 不变。事项的 `group` 是原记录中的可选字段，通过既有记录同步；不迁移或清空旧记录。
