# 2.19.0 发布摘要

用户明确授权将 feat/focus-coach-atlas 当前版本提交、合并 main 并部署。此发布授权覆盖历史批次“不提交/部署”限制，不代表视觉全部验收。

## 范围

- 104目录动作统一resolver与火柴人示范接入训练页；新增只读运动总览、搜索筛选及移动抽屉入口。
- 固定支撑/器械与采样模型、播放器慢放及生命周期清理；真实SVG边界回归，分页/相位视觉审查预览。
- 运动指标按动作区分，游泳米输入/km存储、爬楼楼层/步数、跳绳次数、跑步机恒定段可选速度/坡度；空值/显式零/历史未知字段保留。
- 首页纯有氧不显示力量容量；图鉴静态保持按钮与参考链接修正。
- 独立指标预览及Vite纯模块chunk，避免隔离预览带入store/auth副作用。

## 数据与兼容

localStorage数据键、kind/schema_version、同步协议未改变；不迁移个人历史数据。可选set指标扩展依本会话授权，详见workout-metrics.md。旧客户端可能删除仅楼层/次数等新指标的组，不建议混用旧版编辑这些记录。战绳记录形态保持原样。

## 已知未验边界

104图已接入，但视觉验收仍未完成，motion-progress.json complete=false。部分静态截图已复查，不能替代全周期/多视口认可；羽毛球可靠正文仍待补，部分运动仅限定变式。真实WorkoutUI持续输入焦点、手机软键盘/触控、完整草稿历史交互及云端同步端到端仍未验。已有隔离合成数据浏览器通过证据不扩大为正式数据验收。

发布只改变线上静态代码，不执行数据库迁移或访问修改真实训练记录。回退通过回退发布提交/原GitHub Pages流程执行，不重写Git历史。
