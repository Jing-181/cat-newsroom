# 功能说明

> 更新日期：2026-09-01。本文描述仓库当前已实现的功能，不把规划项视为现有能力。

## 产品定位

「猫咪生活报」是一套复古报刊风格的个人生活工作台，提供桌面与移动两套布局；未登录时可在本机使用，登录正式账号后可通过 Supabase 在多设备间同步数据。

## 已实现功能

| 分类 | 功能 | 说明 |
| --- | --- | --- |
| 访问与适配 | 统一入口与双端布局 | 自动按视口及输入设备进入桌面或移动版；可手动选择“自动 / 桌面 / 移动”，并记住当前浏览器偏好与所在模块。 |
| 首页与洞察 | 工作台总览 | 首页汇总今日聚焦、快速记录、任务、习惯、番茄钟、趋势、账本、阅读和运动；洞察页展示各模块概况。 |
| 待办 | 今日计划 | 新建、编辑、完成待办，设置优先级；支持搜索和将重要事项置顶到“今日聚焦”。 |
| 习惯 | 习惯打卡 | 创建习惯、按天打卡、查看本周完成情况与连续天数。 |
| 阅读 | 阅读进度 | 记录书名、页数进度、摘录及想法，并在首页查看在读书籍进度。 |
| 运动 | 训练日志 | 按胸、背、肩、腿、手臂、全身、有氧恢复日选择预置动作；训练时长由用户手动填写，不做自动计时；记录动作组数、重量、次数，RPE / RIR / 备注收进“更多”；已录的组自动收成一行（如 20kg × 10），只展开当前要填的组，可点“收起本组”收拢，聚焦下一个动作时自动收起其余动作；录完自动进入下一组并继承上一组数据；训练区显示上次每组明细（如 20×10 / 20×10 / 17.5×12）；动作脚部按肌群给出组间歇建议（大肌群 2-3 分钟、小肌群 1 分钟），只做参考、不倒计时，训练计划卡沿用同一口径；训练区提供“动作进展”入口，可查看动作维度的长期轨迹（近几次组次变化）；一组有数值即算一条训练记录，没练的组直接删掉；支持历史训练详情、编辑、删除及补录。动作库没收录的动作可以自己命名后加入本次训练，名字相同的自定义动作在“动作进展”里连成同一条轨迹。旧版运动进度记录仍可查看和编辑。 |
| 专注 | 番茄钟 | 25 分钟专注 / 5 分钟休息；开始后进入全屏专注界面，可暂停、继续、提前结束或重置；以绝对结束时间计时，刷新、后台或锁屏后可恢复，完成数据会累计到番茄统计。 |
| 记录 | 日记与收藏 | 在猫咪日记、今日收藏等模块中创建、编辑、搜索与删除记录。记录卡支持标准、大图、引文样式，并可使用内置配图、外链图片或上传图片。 |
| 账本 | 收支记录 | 记录收入、支出与分类，查看本月收入、支出、结余及分类占比。 |
| 复盘 | 趋势与训练周复盘 | 保存每日趋势数据；训练周复盘由云端定时任务每周一 07:30 写入，前端只读展示：一句话结论、本周/上周对照表、分节复盘、下周提示，可切往期并导出 Markdown；不在浏览器里生成。 |
| 数据 | 本地保存与云同步 | 本地数据自动保存；匿名用户拥有独立会话，正式账号可注册、登录、退出并同步。普通增删改使用单条原子同步，失败操作进入 outbox 后重试；首次进入和“立即同步”执行全量合并，支持 Realtime 更新及删除墓碑，避免已删除记录复活。 |
| 安全 | 图片与数据隔离 | Supabase RLS 按用户隔离业务数据；图片仅允许正式账号上传 JPG、PNG、WebP、GIF，单文件不超过 6 MB，并按用户目录隔离写入。 |

## 使用边界

- 两端页面仅在**相同域名、协议和端口**下共享浏览器本地数据；跨浏览器或跨设备需要登录同一正式账号。
- 每日一卡与训练计划需要完成 Supabase 配置且使用正式账号；训练周复盘是公开只读视图，不需要登录；图片上传需要正式账号。
- 训练记录当前统一使用 kg，不提供公斤/磅自动换算，也不提供医疗建议、动作视频或姿态识别；自定义动作只进训练记录、不写进预置动作库，记录随账号同步，换设备也能从「你用过的自定义动作」里点回来。
